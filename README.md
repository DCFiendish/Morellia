# nodes

Fork of [Aechronis/nodes](https://github.com/Aechronis/nodes) — land protection and nation
simulation library for Minestom, originally created by the Aechronis project. All credit for
the original design and implementation belongs to Aechronis; this fork exists to carry
Morellia-specific fixes and changes on top of their work.

See [`upstream`](https://github.com/Aechronis/nodes) for the original project.
