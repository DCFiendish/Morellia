# vanilla

Fork of [Aechronis/vanilla](https://github.com/Aechronis/vanilla) — a library reimplementing
many vanilla-like features in Minestom, originally created by the Aechronis project. All credit
for the original design and implementation belongs to Aechronis; this fork exists to carry
Nodisium-specific fixes and changes on top of their work.

See [`upstream`](https://github.com/Aechronis/vanilla) for the original project.
